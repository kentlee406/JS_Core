## 第十二章  ES6 章節：Class
### 12-1 Class基礎與建構函式的關係
ES6 的 `class` 是讓「物件導向」寫起來更直覺的語法。**它本質上仍是「建構函式 + 原型（prototype）」的語法糖**，並不是 JavaScript 新增了另一種物件模型。

#### 一、ES5：建構函式 + prototype
```
function Person(name, age) {          // 建構函式（慣例：首字母大寫）
  this.name = name;                   // 實例屬性：每個物件各一份
  this.age = age;
}

Person.prototype.sayHi = function () {   // 方法放在 prototype：所有實例共用一份
  console.log(`我是 ${this.name}，${this.age} 歲`);
};

const p1 = new Person("Ming", 20);
const p2 = new Person("Lee", 25);
p1.sayHi();                            // 我是 Ming，20 歲
console.log(p1.sayHi === p2.sayHi);    // true：共用同一個函式，節省記憶體
```
`new Person(...)` 做了四件事：
1. 建立一個空物件 `{}`。
2. 把該物件的 `__proto__` 指向 `Person.prototype`。
3. 執行 `Person`，其中的 `this` 指向該新物件。
4. 回傳這個新物件（除非建構函式自己 return 了另一個物件）。

#### 二、ES6：class 語法
```
class Person {
  constructor(name, age) {      // 建構子：new 的時候自動執行
    this.name = name;
    this.age = age;
  }

  sayHi() {                      // 方法：自動放在 Person.prototype
    console.log(`我是 ${this.name}，${this.age} 歲`);
  }
}

const p = new Person("Ming", 20);
p.sayHi();     // 我是 Ming，20 歲
```
* `constructor` 就是原本的建構函式本體；`class` 裡的方法**不需要加 `function` 關鍵字，方法之間也不要加逗號**。
* 一個 class 只能有**一個** `constructor`；沒寫的話會有預設的空 constructor。

#### 三、證明 class 就是函式
```
console.log(typeof Person);                          // "function"
console.log(Person === Person.prototype.constructor); // true
console.log(p.__proto__ === Person.prototype);        // true
console.log(typeof Person.prototype.sayHi);           // "function"：方法確實在 prototype 上
console.log(p.hasOwnProperty("name"));                // true：實例屬性
console.log(p.hasOwnProperty("sayHi"));               // false：方法在原型上，不屬於實例本身
```
```
實例 p ──__proto__──→ Person.prototype ──__proto__──→ Object.prototype ──→ null
 name, age             constructor, sayHi              toString ...
```

#### 四、class 與 ES5 建構函式的差異（重要）
| 比較項目 | ES5 建構函式 | ES6 class |
| --- | --- | --- |
| 不加 `new` 呼叫 | 能呼叫（`this` 會跑到全域，造成錯誤） | **TypeError**：Class constructor cannot be invoked without 'new' |
| Hoisting（提升） | 函式宣告會整個提升，宣告前可使用 | 與 `let` 相同：有暫時性死區，**宣告前使用會 ReferenceError** |
| 方法是否可列舉（for...in） | 用 `prototype.xxx =` 加入的方法**可列舉** | class 內的方法**不可列舉** |
| 嚴格模式 | 預設非嚴格 | **class 內部自動是嚴格模式** |
| 繼承 | 需手動處理 prototype 鏈 | `extends` + `super` |

```
function Old(name) { this.name = name; }
Old("a");                 // 沒報錯，但 this 指向全域，name 變成全域變數（汙染）

class New { constructor(name) { this.name = name; } }
New("a");                 // TypeError: Class constructor New cannot be invoked without 'new'

new Later();              // ReferenceError: Cannot access 'Later' before initialization
class Later {}
```

#### 五、類別宣告與類別運算式
```
// 1. 類別宣告
class A {}

// 2. 類別運算式（匿名）
const B = class {};

// 3. 具名類別運算式（名稱只能在 class 內部使用）
const C = class Inner {
  who() { return Inner.name; }
};
console.log(new C().who());    // "Inner"
```

#### 六、實例屬性的兩種寫法
```
class Counter {
  count = 0;                    // 類別欄位（Class Fields，ES2022）：每個實例一份
  step;                         // 沒有賦值則為 undefined

  constructor(step = 1) {
    this.step = step;
  }

  add() {
    this.count += this.step;
    return this.count;
  }
}

const c = new Counter(5);
console.log(c.add(), c.add());   // 5 10
```
* 在 `constructor` 中用 `this.xxx =` 是傳統做法，所有環境都支援。
* 在 class 本體直接寫 `count = 0;` 是 ES2022 的類別欄位，語法簡潔，須注意舊版瀏覽器的支援度。

### 12-2 Class實戰常用方法

#### 一、實例方法與 getter / setter
```
class Rectangle {
  constructor(w, h) {
    this.w = w;
    this.h = h;
  }

  // getter：像屬性一樣讀取，但背後是函式（不需括號）
  get area() {
    return this.w * this.h;
  }

  // setter：像屬性一樣賦值，可以在賦值時加入驗證
  set width(value) {
    if (value <= 0) throw new RangeError("寬度必須大於 0");
    this.w = value;
  }
  get width() {
    return this.w;
  }

  // 一般方法
  toString() {
    return `Rectangle(${this.w} x ${this.h})`;
  }
}

const r = new Rectangle(3, 4);
console.log(r.area);        // 12（注意：沒有括號）
r.width = 5;                // 觸發 setter
console.log(r.area);        // 20
console.log(`${r}`);        // Rectangle(5 x 4)
r.width = -1;               // RangeError: 寬度必須大於 0
```
* 只有 getter 沒有 setter 的屬性是**唯讀**（在嚴格模式下賦值會 TypeError，class 內為嚴格模式）。
* getter 每次讀取都會重新計算，適合「由其他屬性衍生出來的值」。

#### 二、靜態方法與靜態屬性（static）
屬於 **class 本身**，不屬於實例，用「類別名稱.方法」呼叫。

```
class MathUtil {
  static PI = 3.14159;                  // 靜態屬性

  static circleArea(r) {                // 靜態方法
    return MathUtil.PI * r * r;
  }
}

console.log(MathUtil.circleArea(2));    // 12.56636
const m = new MathUtil();
console.log(m.circleArea);              // undefined：實例拿不到靜態成員
```
典型用途：**工具函式**、**工廠方法**、**計數器**。

```
class User {
  static count = 0;

  constructor(name) {
    this.name = name;
    User.count++;                       // 每建立一個實例就累加
  }

  // 工廠方法：用不同的方式建立實例
  static fromJSON(json) {
    const { name } = JSON.parse(json);
    return new User(name);
  }
}

new User("A");
User.fromJSON('{"name":"B"}');
console.log(User.count);                // 2
```

#### 三、私有欄位與私有方法（#）
以 `#` 開頭的成員，**只能在 class 內部存取**，外部存取直接 SyntaxError，是真正的封裝。

```
class BankAccount {
  #balance = 0;                         // 私有欄位

  constructor(owner, initial = 0) {
    this.owner = owner;
    this.#balance = initial;
  }

  deposit(amount) {
    this.#validate(amount);
    this.#balance += amount;
    return this;
  }

  withdraw(amount) {
    this.#validate(amount);
    if (amount > this.#balance) throw new Error("餘額不足");
    this.#balance -= amount;
    return this;
  }

  get balance() {                       // 對外只提供讀取
    return this.#balance;
  }

  #validate(amount) {                   // 私有方法
    if (amount <= 0) throw new Error("金額必須大於 0");
  }
}

const acc = new BankAccount("Ming", 100);
acc.deposit(50).withdraw(30);
console.log(acc.balance);               // 120
console.log(acc.#balance);              // SyntaxError：Private field '#balance' must be declared in an enclosing class
acc.balance = 999;                      // 沒有 setter，嚴格模式下 TypeError
```
> 舊式的替代方案：用底線約定 `_balance` 表示「請不要直接使用」，但這只是君子協定，外部仍然可以改。

#### 四、繼承：extends 與 super
```
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(`${this.name} 發出聲音`);
  }
  get info() {
    return `動物：${this.name}`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);                       // ① 必須先呼叫 super()，才能使用 this
    this.breed = breed;
  }

  speak() {                            // ② 覆寫（override）父類別的方法
    super.speak();                     // ③ 呼叫父類別的同名方法
    console.log(`${this.name}：汪汪！`);
  }

  get info() {
    return `${super.info}，品種：${this.breed}`;
  }
}

const d = new Dog("小黑", "柴犬");
d.speak();
// 小黑 發出聲音
// 小黑：汪汪！
console.log(d.info);                   // 動物：小黑，品種：柴犬
console.log(d instanceof Dog, d instanceof Animal);   // true true
console.log(Object.getPrototypeOf(Dog) === Animal);   // true：Dog 的原型就是 Animal（靜態成員也會繼承）
```
* 子類別的 `constructor` 裡，**使用 `this` 之前必須先呼叫 `super()`**，否則 `ReferenceError: Must call super constructor in derived class before accessing 'this'`。
* 如果子類別完全不寫 `constructor`，會自動補上 `constructor(...args) { super(...args); }`。
* `super.method()` 呼叫父類別方法；`super(...)` 呼叫父類別建構子。

#### 五、多型示範
```
class Shape {
  area() { throw new Error("子類別必須實作 area()"); }
  describe() { return `${this.constructor.name} 的面積是 ${this.area().toFixed(2)}`; }
}
class Circle extends Shape {
  constructor(r) { super(); this.r = r; }
  area() { return Math.PI * this.r ** 2; }
}
class Square extends Shape {
  constructor(s) { super(); this.s = s; }
  area() { return this.s ** 2; }
}

[new Circle(1), new Square(2)].forEach(s => console.log(s.describe()));
// Circle 的面積是 3.14
// Square 的面積是 4.00
```

#### 六、instanceof、toString、Symbol.iterator
```
class Playlist {
  constructor(...songs) { this.songs = songs; }

  // 讓物件可以被 for...of 與展開運算子使用
  *[Symbol.iterator]() {
    for (const s of this.songs) yield s;
  }
}

const list = new Playlist("A", "B", "C");
for (const s of list) console.log(s);     // A B C
console.log([...list]);                   // ["A", "B", "C"]
```

#### 七、常見錯誤
```
// ❌ 1. class 內的方法之間加逗號
class Bad {
  a() {},        // SyntaxError
  b() {}
}

// ❌ 2. 子類別未呼叫 super 就使用 this
class Child extends Animal {
  constructor() { this.x = 1; }     // ReferenceError
}

// ❌ 3. 在 class 內忘了 this
class Counter {
  count = 0;
  add() { count++; }                // ReferenceError: count is not defined（要寫 this.count++）
}

// ❌ 4. 不用 new
const p = Person("a");              // TypeError
```

### 12-3 Class與this的進階使用技巧

#### 一、class 方法中的 this 是「呼叫時」決定的
`this` 指向「**呼叫這個方法的物件**」（點號前面的那個東西），而不是「方法定義在哪裡」。

```
class Person {
  constructor(name) { this.name = name; }
  sayHi() { console.log("Hi, " + this.name); }
}

const p = new Person("Ming");
p.sayHi();                 // Hi, Ming：this 是 p
```

#### 二、常見問題：方法被「取出」後 this 遺失
```
const fn = p.sayHi;        // 只拿出函式，與 p 失去關係
fn();                      // TypeError: Cannot read properties of undefined (reading 'name')
```
* class 內部是嚴格模式，獨立呼叫的函式 `this` 是 `undefined`（非嚴格模式則是 `window`），所以會報錯。
* 最常發生的情境：**把方法當成 callback 傳出去**。

```
class Timer {
  constructor() { this.seconds = 0; }
  tick() { this.seconds++; console.log(this.seconds); }

  startBad() {
    setInterval(this.tick, 1000);          // ❌ this.tick 被取出，執行時 this 不是 Timer
  }
}

button.addEventListener("click", p.sayHi);   // ❌ 事件處理函式中的 this 會變成 button（DOM 元素）
```

#### 三、四種解法
```
class Timer {
  constructor() {
    this.seconds = 0;
    // 解法 1：在 constructor 中 bind（每個實例各有一個綁定後的函式）
    this.tick = this.tick.bind(this);
  }
  tick() { this.seconds++; console.log(this.seconds); }
}
```
```
// 解法 2：呼叫時使用 bind
setInterval(timer.tick.bind(timer), 1000);

// 解法 3：呼叫時包一層箭頭函式
setInterval(() => timer.tick(), 1000);
button.addEventListener("click", () => p.sayHi());

// 解法 4：把方法寫成「箭頭函式的類別欄位」（最常用，ES2022）
class Timer2 {
  seconds = 0;
  tick = () => {                       // 箭頭函式不產生自己的 this，使用「定義時」外層的 this，即實例
    this.seconds++;
    console.log(this.seconds);
  };
}
const t = new Timer2();
const { tick } = t;
tick();     // 1：即使取出，this 仍然正確
```
| 解法 | 優點 | 缺點 |
| --- | --- | --- |
| constructor 中 `bind` | 通用，相容性好 | 每個方法都要寫一次 |
| 呼叫時 `bind` / 箭頭函式包一層 | 彈性高，不改 class | 使用端容易忘記；`bind` 每次會產生新函式，移除事件監聽很麻煩 |
| 箭頭函式類別欄位 | 寫法最簡潔，不怕 this 遺失 | 方法**每個實例都各自複製一份**（不在 prototype 上），無法被子類別用 `super.tick()` 呼叫 |

#### 四、箭頭函式方法的限制
```
class A {
  normal() {}                  // 在 A.prototype 上，所有實例共用
  arrow = () => {};            // 在每個實例自己身上
}
const a1 = new A(), a2 = new A();
console.log(a1.normal === a2.normal);   // true
console.log(a1.arrow  === a2.arrow);    // false：各自一份
console.log(A.prototype.arrow);         // undefined
```
→ 需要被繼承、覆寫、或是要建立大量實例時，優先使用一般方法，需要當作 callback 時再使用 `bind` 或箭頭函式。

#### 五、方法鏈（Method Chaining）：回傳 this
```
class Calculator {
  constructor(value = 0) { this.value = value; }
  add(n)      { this.value += n; return this; }     // 回傳 this，才能繼續呼叫
  subtract(n) { this.value -= n; return this; }
  multiply(n) { this.value *= n; return this; }
  result()    { return this.value; }
}

console.log(new Calculator(10).add(5).multiply(2).subtract(6).result());   // 24
```
* 方法最後 `return this`，呼叫端就能連續用點號串接。
* 這也是 jQuery 的核心設計；先前銀行帳戶範例的 `deposit().withdraw()` 也使用同樣技巧。

#### 六、巢狀函式中的 this
```
class Team {
  constructor(name, members) {
    this.name = name;
    this.members = members;
  }

  // ❌ 一般函式的 callback：this 不是實例
  listBad() {
    this.members.forEach(function (m) {
      console.log(this.name + "：" + m);        // TypeError：this 是 undefined
    });
  }

  // ✅ 箭頭函式：繼承外層方法的 this
  list() {
    this.members.forEach(m => {
      console.log(this.name + "：" + m);
    });
  }

  // ✅ forEach 第二個參數可指定 this
  list2() {
    this.members.forEach(function (m) {
      console.log(this.name + "：" + m);
    }, this);
  }
}
new Team("A 隊", ["小明", "小華"]).list();
// A 隊：小明
// A 隊：小華
```
* 回顧第八章：**箭頭函式沒有自己的 this**，會沿用定義它的外層 this；因此在方法內部寫 callback 時，箭頭函式是最好的選擇。

#### 七、靜態方法中的 this
```
class Config {
  static env = "dev";
  static show() {
    console.log(this.env);         // 靜態方法的 this 是「class 本身」
  }
}
Config.show();                     // "dev"

class ProdConfig extends Config {
  static env = "prod";
}
ProdConfig.show();                 // "prod"：this 是 ProdConfig（呼叫者），能被繼承與覆寫
```

#### 八、在 constructor 中的 new.target 與抽象類別
```
class AbstractShape {
  constructor() {
    if (new.target === AbstractShape) {
      throw new TypeError("AbstractShape 是抽象類別，不能直接實例化");
    }
  }
}
class Tri extends AbstractShape {}

new Tri();               // OK
new AbstractShape();     // TypeError
```
`new.target` 指向「被 new 的那個類別」，常用來模擬抽象類別。

#### 九、call / apply 借用方法
```
class Greeter {
  hello() { return "Hello, " + this.name; }
}
const g = new Greeter();
console.log(g.hello.call({ name: "Lee" }));   // Hello, Lee：用 call 暫時換掉 this
```

### 12-4 使用Class擴充原始陣列方法

#### 一、為什麼要擴充陣列？
內建的 `Array` 沒有的功能（如 `sum`、`average`、`unique`、`groupBy`），可以自己加。有兩種做法：

| 做法 | 範例 | 評價 |
| --- | --- | --- |
| 修改原生原型 | `Array.prototype.sum = function(){}` | ❌ **不建議**（汙染全域，可能與未來標準或其他套件衝突） |
| 繼承 `Array` | `class MyArray extends Array` | ✅ **建議**：只影響自己的類別，保留所有原生方法 |

> 修改 `Array.prototype` 還有一個副作用：`for...in` 遍歷陣列時會連自己加的方法也一起列舉出來。

```
// ❌ 不建議的做法（僅示範）
Array.prototype.sum = function () { return this.reduce((a, b) => a + b, 0); };
console.log([1, 2, 3].sum());    // 6，但所有陣列都被改了
```

#### 二、繼承 Array 的基本用法
```
class MyArray extends Array {
  sum() {
    return this.reduce((a, b) => a + b, 0);
  }

  average() {
    return this.length === 0 ? 0 : this.sum() / this.length;
  }

  get first() { return this[0]; }
  get last()  { return this[this.length - 1]; }
}

const arr = new MyArray(1, 2, 3, 4);
console.log(arr);              // MyArray(4) [1, 2, 3, 4]
console.log(arr.length);       // 4
console.log(arr.sum());        // 10
console.log(arr.average());    // 2.5
console.log(arr.first, arr.last);          // 1 4
console.log(Array.isArray(arr));           // true：它仍然是真正的陣列
console.log(arr instanceof MyArray, arr instanceof Array);   // true true
```
* 原生的 `push`、`pop`、`forEach`、`length` 自動行為（改變長度）都完全保留。
* 建立方式可使用 `new MyArray(1, 2, 3)`、`MyArray.from([1, 2, 3])`、`MyArray.of(1, 2, 3)`。

#### 三、注意：new MyArray(n) 的陷阱（與 Array 相同）
```
new MyArray(3);          // MyArray(3) [ <3 empty items> ]：只有一個數字參數時，代表「長度」
new MyArray(3, 4);       // MyArray(2) [3, 4]
MyArray.of(3);           // MyArray(1) [3]  ← 想放入單一數字時，用 of 比較安全
MyArray.from([3]);       // MyArray(1) [3]
```

#### 四、Symbol.species：map / filter 會回傳什麼類型？
繼承 `Array` 後，`map`、`filter`、`slice`、`concat` 等會**回傳同一個子類別的新實例**，所以可以繼續使用自訂方法：

```
const nums = MyArray.from([1, 2, 3, 4, 5, 6]);

const evens = nums.filter(n => n % 2 === 0);
console.log(evens instanceof MyArray);     // true
console.log(evens.sum());                  // 12：filter 的結果還能直接呼叫 sum()

const doubled = nums.map(n => n * 2);
console.log(doubled.average());            // 7
```
如果希望這些方法回傳**一般陣列**，可以覆寫靜態的 `Symbol.species`：

```
class PlainResultArray extends Array {
  static get [Symbol.species]() { return Array; }
}
const x = PlainResultArray.from([1, 2, 3]);
console.log(x.map(n => n) instanceof PlainResultArray);   // false
console.log(x.map(n => n) instanceof Array);              // true
```

#### 五、實用範例：打造 Collection
```
class Collection extends Array {
  // 去除重複
  unique() {
    return Collection.from(new Set(this));
  }

  // 依條件分組：groupBy(item => key) → { key: Collection }
  groupBy(fn) {
    return this.reduce((groups, item) => {
      const key = fn(item);
      (groups[key] ||= new Collection()).push(item);
      return groups;
    }, {});
  }

  // 取出每個物件的某個欄位
  pluck(key) {
    return this.map(item => item[key]);
  }

  // 隨機取得一個
  random() {
    return this[Math.floor(Math.random() * this.length)];
  }

  // 分成固定大小的小組：chunk(2) → [[1,2],[3,4],[5]]
  chunk(size) {
    const result = new Collection();
    for (let i = 0; i < this.length; i += size) {
      result.push(this.slice(i, i + size));
    }
    return result;
  }

  // 不改變原陣列的洗牌
  shuffle() {
    const copy = Collection.from(this);
    for (let i = copy.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [copy[i], copy[j]] = [copy[j], copy[i]];
    }
    return copy;
  }
}

const c = Collection.from([1, 2, 2, 3, 3, 3, 4, 5]);
console.log(c.unique());              // Collection(5) [1, 2, 3, 4, 5]
console.log(c.unique().chunk(2));     // [[1, 2], [3, 4], [5]]

const users = Collection.from([
  { name: "Ming", city: "台北" },
  { name: "Lee",  city: "高雄" },
  { name: "Wang", city: "台北" }
]);
console.log(users.pluck("name"));                     // ["Ming", "Lee", "Wang"]
const groups = users.groupBy(u => u.city);
console.log(groups["台北"].pluck("name"));            // ["Ming", "Wang"]
```
> `||=` 是 ES2021 的邏輯指派運算子：`a ||= b` 等同 `a || (a = b)`。

#### 六、覆寫原生方法並呼叫 super
```
class LoggedArray extends Array {
  push(...items) {
    console.log("新增：", items);
    return super.push(...items);      // 呼叫原本的 Array.prototype.push
  }
}
const la = new LoggedArray();
la.push(1, 2);        // 新增： [1, 2]
console.log(la.length);   // 2
```

#### 七、不使用 class 的對照：ES5 繼承 Array 的困難
在 ES5 中用 `Array.call(this)` 繼承陣列會失敗（`length` 不會自動隨元素變動），這也是 ES6 `class extends Array` 的價值之一。

```
function OldArr() { Array.apply(this, arguments); }
OldArr.prototype = Object.create(Array.prototype);
const o = new OldArr();
o.push(1, 2);
console.log(o.length);              // 2（push 靠 length 屬性運作，看起來可以）
o[5] = 9;
console.log(o.length);              // 2：直接以索引賦值，length 不會更新！（真正的陣列會是 6）
```

#### 八、小結
* 擴充陣列：優先使用 `class extends Array`，不要改 `Array.prototype`。
* 子類別會保留所有原生功能，且 `map`、`filter` 等會回傳子類別實例，可連續使用自訂方法（鏈式呼叫）。
* 想要只用單一數字建立陣列時，用 `.of()` 避免被當成長度。
* 需要回傳原生陣列時，覆寫 `Symbol.species`。

#### 第一題
請把下列 ES5 的建構函式寫法，改寫成 ES6 的 class。
```
function Student(name, score) {
  this.name = name;
  this.score = score;
}
Student.prototype.isPass = function () {
  return this.score >= 60;
};
Student.create = function (name, score) {
  return new Student(name, score);
};
```
**答：**
```
class Student {
  constructor(name, score) {
    this.name = name;
    this.score = score;
  }

  isPass() {
    return this.score >= 60;
  }

  static create(name, score) {
    return new Student(name, score);
  }
}

const s = Student.create("Ming", 75);
console.log(s.isPass());     // true
```
**詳解：**
* 建構函式本體 → `constructor`。
* 原本掛在 `Student.prototype` 上的方法 → class 內的一般方法。
* 直接掛在建構函式上的 `Student.create`（靜態成員）→ 加上 `static` 關鍵字。

#### 第三題
請設計 `Temperature` 類別：
1. 以攝氏溫度建立：`new Temperature(25)`。
2. 提供 getter `fahrenheit`（華氏 = 攝氏 × 9 / 5 + 32）。
3. 提供 setter `fahrenheit`，可以用華氏設定溫度。
4. 提供靜態方法 `Temperature.fromFahrenheit(f)` 建立實例。
5. 攝氏溫度不得低於絕對零度 -273.15，否則丟出 `RangeError`。

**答：**
```
class Temperature {
  #celsius;

  constructor(celsius) {
    this.celsius = celsius;          // 透過 setter 做驗證
  }

  get celsius() {
    return this.#celsius;
  }
  set celsius(value) {
    if (value < -273.15) throw new RangeError("不可低於絕對零度 -273.15");
    this.#celsius = value;
  }

  get fahrenheit() {
    return this.#celsius * 9 / 5 + 32;
  }
  set fahrenheit(f) {
    this.celsius = (f - 32) * 5 / 9;
  }

  static fromFahrenheit(f) {
    const t = new Temperature(0);
    t.fahrenheit = f;
    return t;
  }
}

const t = new Temperature(25);
console.log(t.fahrenheit);                       // 77
t.fahrenheit = 212;
console.log(t.celsius);                          // 100
console.log(Temperature.fromFahrenheit(32).celsius);   // 0
new Temperature(-300);                           // RangeError
```
**詳解：**
* 用私有欄位 `#celsius` 存放真正的值，外部無法繞過驗證直接修改。
* 在 `constructor` 中寫 `this.celsius = celsius`，會觸發 setter，建立物件時也會驗證。
* 靜態方法 `fromFahrenheit` 是工廠方法，內部再借用 `fahrenheit` setter 做轉換。

class Cat extends Animal {

#### 第五題
下列程式碼為何點擊按鈕後會發生錯誤？請提出至少兩種修正方式。
```
class Counter {
  constructor(btn) {
    this.count = 0;
    btn.addEventListener("click", this.increase);
  }
  increase() {
    this.count++;
    console.log(this.count);
  }
}
new Counter(document.querySelector("#btn"));
```
**答：**
* 原因：`this.increase` 被當成 callback 傳出，事件觸發時 `this` 是**被點擊的按鈕**（DOM 元素），不是 `Counter` 實例，所以 `this.count++` 變成 `button.count = NaN`（`undefined + 1`），印出 `NaN`，並不會得到預期的 1、2、3。

**修正方式：**
```
// 1. constructor 內 bind
btn.addEventListener("click", this.increase.bind(this));

// 2. 箭頭函式包一層
btn.addEventListener("click", () => this.increase());

// 3. 方法改成箭頭函式類別欄位
class Counter {
  count = 0;
  constructor(btn) { btn.addEventListener("click", this.increase); }
  increase = () => {
    this.count++;
    console.log(this.count);
  };
}
```
**詳解：**
* 方法 1、2 都能固定 this；若之後需要 `removeEventListener`，方法 1 每次呼叫 `bind` 都會產生新函式，必須先把綁定後的函式存起來才能移除。
* 方法 3 最簡潔，代價是方法變成各實例各自擁有一份。

#### 第六題
請設計 `Stack`（堆疊，後進先出）類別，使用私有欄位存放資料，提供 `push(item)`、`pop()`、`peek()`、`isEmpty()`、`size` getter，並支援方法鏈（`push` 回傳 `this`）。

**答：**
```
class Stack {
  #items = [];

  push(item) {
    this.#items.push(item);
    return this;                       // 方法鏈
  }

  pop() {
    return this.#items.pop();          // 空堆疊會得到 undefined
  }

  peek() {
    return this.#items[this.#items.length - 1];
  }

  isEmpty() {
    return this.#items.length === 0;
  }

  get size() {
    return this.#items.length;
  }
}

const s = new Stack();
s.push(1).push(2).push(3);
console.log(s.size);        // 3
console.log(s.peek());      // 3
console.log(s.pop());       // 3
console.log(s.pop());       // 2
console.log(s.isEmpty());   // false
console.log(s.size);        // 1
console.log(s.items);       // undefined：外部看不到私有資料
```
**詳解：**
* 資料放在 `#items`，外部無法直接修改陣列，只能透過我們提供的方法（封裝）。
* `push` 回傳 `this` 達成鏈式呼叫；`size` 使用 getter，讀取時不加括號。

#### 第七題
請繼承 `Array` 建立 `NumberList` 類別，提供：
1. `sum()`：加總。
2. `max()`：最大值（空陣列回傳 `undefined`）。
3. `average()`：平均（空陣列回傳 0）。

並說明 `list.filter(n => n > 2).sum()` 為何可以運作。

**答：**
```
class NumberList extends Array {
  sum() {
    return this.reduce((a, b) => a + b, 0);
  }

  max() {
    return this.length ? Math.max(...this) : undefined;
  }

  average() {
    return this.length ? this.sum() / this.length : 0;
  }
}

const list = NumberList.of(1, 2, 3, 4, 5);
console.log(list.sum());                   // 15
console.log(list.max());                   // 5
console.log(list.average());               // 3
console.log(list.filter(n => n > 2).sum());// 12（3 + 4 + 5）
console.log(new NumberList().average());   // 0
console.log(new NumberList().max());       // undefined
```
**詳解：**
* 使用 `NumberList.of(...)` 而非 `new NumberList(5)`，避免單一數字被當成「長度」。
* 繼承 `Array` 後，`filter`、`map`、`slice` 等方法會依 `Symbol.species`（預設為建構該物件的子類別），回傳 **`NumberList` 的新實例**，因此回傳值也擁有 `sum()` 方法，可以直接鏈式呼叫。
* `Math.max(...this)` 以展開運算子把陣列轉成參數；空陣列時 `Math.max()` 會得到 `-Infinity`，所以先判斷長度。

#### 第八題
下列程式碼的輸出為何？
```
class Base {
  static who() { return this.name; }
  hello() { return "Hello from " + this.constructor.name; }
}
class Derived extends Base {}

console.log(Base.who());
console.log(Derived.who());
console.log(new Derived().hello());
console.log(Object.getPrototypeOf(Derived) === Base);
console.log(Derived.prototype.__proto__ === Base.prototype);
```
**答：**
```
Base
Derived
Hello from Derived
true
true
```
**詳解：**
* 靜態方法的 `this` 是**呼叫它的 class**。`Base.who()` 的 this 是 `Base`，`Derived.who()` 的 this 是 `Derived`（靜態成員會被繼承），`name` 屬性是 class 的名稱。
* 實例方法的 `this.constructor` 指向實例的建構子，所以是 `Derived`。
* `extends` 同時建立了**兩條**原型鏈：
  * 類別本身：`Derived.__proto__ === Base`（繼承靜態成員）。
  * 實例原型：`Derived.prototype.__proto__ === Base.prototype`（繼承實例方法）。
